# Contributing to Typeset.md

Bug reports and feature requests are welcome in [issues](https://github.com/deeflect/typeset/issues). For anything bigger than a small fix, open an issue before writing code so the work is not wasted.

## Building

See [BUILDING.md](BUILDING.md).
